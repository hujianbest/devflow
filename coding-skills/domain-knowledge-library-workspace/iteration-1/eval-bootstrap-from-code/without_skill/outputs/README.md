## 可信度与状态约定

| 标记 | 含义 |
|---|---|
| **实现事实** | 可直接由当前代码、测试或契约证明；不等于业务政策已经被人工确认 |
| **候选业务语义** | 为帮助团队讨论而提出的解释或推测，不应直接作为需求、验收标准或运营政策 |
| **未知/待确认** | 输入材料没有给出答案 |

证据优先级不自动决定业务真相：生产代码说明当前逻辑，测试说明已显式覆盖的示例，契约说明公开接口意图；三者均可能不完整。本知识库中没有任何条目被标记为“人工审核”或“业务确认”。

## 当前范围

范围仅包含订单取消。输入中没有创建、支付、发货、查询、退款、库存、鉴权、持久化或消息发布的实现与契约，因而这些能力不在当前已知边界内。
