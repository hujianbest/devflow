## 维护规则

1. 新增实现事实时必须附文件与行号，或附可稳定定位的符号。
2. 代码行为、测试期望和接口契约分别记录，不因名称相似而声明端到端链路存在。
3. 推测统一标为候选业务语义，只有明确的评审人、日期和依据齐备后才能改为业务已确认。
4. 若来源冲突，保留冲突而不是自行选择“真相”，并交由对应负责人裁决。
