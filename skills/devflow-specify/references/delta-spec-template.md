# 规格增量

## 变换契约

- 应用顺序：`RENAMED → REMOVED → MODIFIED → ADDED`
- 原子性：全部操作前置条件成立后才能同步；任一操作失败时不产生部分结果。
- 保留边界：未被操作精确指向的规格元素、字段、场景、引用和顺序语义保持不变。
- 目标互斥：同一规格 ID 不得同时出现在互斥分区；同一目标的多个操作必须声明依赖并产生唯一结果。

| 操作 ID | 类型 | 目标稳定 ID / 锚点 | 需求来源 | 依赖操作 | 结果摘要 |
