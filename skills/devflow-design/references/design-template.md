# design.md 模板

使用说明：`devflow-design` 生成 `features/<id>-<slug>/design.md` 的默认模板。设计深度跟随影响面：纯内部修改可省略「接口契约」「兼容性」章节，但「测试设计」永不省略。团队 `AGENTS.md` 声明等价模板时优先遵循团队约定。
